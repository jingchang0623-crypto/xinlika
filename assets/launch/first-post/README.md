# 首发配图

GPL-3.0-only；版权与原生上游来源沿用 [上一层素材说明](../README.md)及[客户端来源](../../../clients/PROVENANCE.md)。

- `xiaohongshu/01..05`：5 张 1080 × 1440 竖版图，按编号上传，01 为封面。
- `x/01-cover.png`：直接复用 `../social-preview.png`，1280 × 640 横版图。
- `layout.html?page=1..5`：可编辑排版源，在 1080 × 1440 视口截取。
- `github.svg`：直接编码 `https://github.com/jingchang0623-crypto/xinlika` 的二维码，无跟踪参数或中间跳转。
- `manifest.json`：每张导出图的 SHA-256、尺寸、来源。

`layout.html` 复用上一层未修改的原生截图；界面真实，输入与模型响应为合成夹具。制作时保留硬件价格范围、Android 规划状态及自行构建说明。

最终标题、正文、图片顺序与 X 替代文字见[首发发布说明](../../../docs/launch/first-post/README.md)。
