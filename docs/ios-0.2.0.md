# 0.2.0 (11)：云端历史与本地录音合并展示

## 结论

可以。深脑账号中的录音会话和转写历史可以合并进 App 的「记录」页，因此直接上传、其他设备上传，以及录音卡同步的结果都能在同一个列表里查看。已有本地录音优先保留本地 ID、音频、同步进度和“待确认/已忽略”决定；云端条目只作为只读历史，不会因为刷新记录而重新下载、上传或启动分析。

## 数据来源与合并

- `/api/mobile/sessions` 提供云端录音会话的阶段、标题、时长、转写 ID 和失败原因。
- `transcripts` 只读列表补充直接上传等没有本地会话的条目。查询显式限制当前组织，并以 UUID 游标分批读取，避免只显示最近 100 条。
- 有相同转写 ID 的会话和历史合并成一条；已有本地记录按 `serverSessionId` 或 `transcriptId` 对账，避免重复。
- 云端目录先写入本地缓存，再读取有限数量的结果详情；点击旧条目会强制刷新该条详情。网络失败保留上次列表和正文，并提供重试。
- 云端录音不会成为设备同步任务，也不会进入本地上传队列。云端时长未知时显示“时长未知”，不伪造 0 秒。

云端阶段沿用服务端返回值：录音已保存、转写中、转写完成、分析完成、云端处理失败或状态待确认。未知状态不会被猜成成功。
