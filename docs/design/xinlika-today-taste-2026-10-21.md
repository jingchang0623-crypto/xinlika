## 已完成的原生改动

源码仍用 `HeartballLab` target、既有 Bundle ID 与存储位置，产品窗口、菜单和新 `.build/心力卡.app` 使用心力卡名称，避免名称修改触发旧数据与权限迁移。

`WorkspaceView` / `WorkspaceComponents` / `AgentPanel` 复用既有 `LabModel`、Swift API 客户端和结果操作：

- 中性底色、原生工具栏、较紧凑的文字与分栏，移除紫色渐变、重复说明和重卡片装饰。
- 持续录音和独立重点控制保留，打开 App 不自动开始录音。设备与处理细节集中到底部入口。
- 记录按已有逻辑 session 归组；重点单独筛选，同一重点不重复拼入原始全文。空尾段不再遮住有正文的记录。
- 原声、逐字稿、边界说明按需展开。来源和文字纠正沿用现有持久化接口。
- 记忆筛选、搜索、负责人及可选日期控件使用真实数据，不虚构任务、指标、提醒和当天事件。
- 问答引用可跳回对应记忆或文档。增加系统/浅色/深色选择。

用户要求进一步简化后，源码草稿移除了首页待确认事实队列和主导航处理任务入口，普通内容显示“自动整理”，审核只保留为按需纠正/核实。**这部分不能被说成已经实现自动事件、自动项目或完整 AI 理解。** 当前按 session 归组仅解决文件呈现。

## 验证的范围

- Swift 构建通过。八项本地记录归组检查覆盖 session 身份、重点重叠、旧版本排除、空尾段和空账户；不调用硬件、ASR 或模型。
- 初版中性布局已在实际 Mac 原生应用查看首页、记录、记忆与设备，窗口/菜单显示心力卡，真实历史数据正常可见。原声/纠正/筛选等复用先前 API 链路。
- 后续精简草稿已编译；尚未完成最后版本的浅色/深色、最小/大窗口逐页视觉验收。当前正在运行的应用与服务没有冒称已经加载全部最新源码。
- taste-skill 的网页 DOM/CSS 检查器不支持原生 SwiftUI；未声称通过该检查器，原生界面需要用 Mac 实际窗口验证。
- 后端新增未确认记录可查询、普通事实不再逐条产生审核提醒等改动，Python 33 项回归检查通过；未重启主服务、重处理真实音频或修改历史事实。这是源代码验证，不是完整真实 Personal Agent 体验验收。

## 下一版的呈现约束

首页以 AI 自动形成的事件为中心；主题进展和问 Agent 服务找回与关联。批次和重试留在诊断，原声证据留在详情。用户纠正入口简短、可撤回；不要求逐条批准才能得到总结和回答。不为对齐参考截图先添加没有真实能力的空项目/觉察页。

默认文案只回答当前状态与下一步操作。来源不确定性由 AI 在有影响时处理，避免在每张卡片放整段免责声明。未经新一轮真实语音、跨对话和纠正验收，不以界面更新替代底层能力完成。
