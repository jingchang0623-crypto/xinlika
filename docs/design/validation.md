# 原生设计预览 v1 验证记录

日期：2026-09-05。范围仅为 `ShennaoDesignPreview`，不是生产 App 发布验收。

## 已验证

- iOS 17 deployment target 的预览 scheme 在 Xcode 26.5 编译成功。
- 在 iPhone 17 Pro / iOS 26.5 模拟器运行，独立 bundle `com.zaowuyun.shennao.design-preview`。
- 最终代码 UI 测试 **5 通过、0 失败、0 跳过**。结果包：`/tmp/shennao-native-design-preview-tests-final.xcresult`。
- 路径覆盖：进入记录、原话展开、概览/完整分析切换、目录跳转后目标标题可见、搜索筛选/无结果、跨标签保留阅读模式、暂停演示、空状态与刷新失败恢复。
- 查看过五个页面实际截图；记录页移除了过多的顶部说明、修正分隔线对齐，并提高摘要/判断正文的对比度。
- 查看过深色概览及系统 `accessibility-extra-large` 大字号概览；发现分段控件标签未放大后，改为大字号专用的原生菜单选择器，重新编译、截图并复核。
- 小节标题与数量在辅助功能字号下垂直排列；对照表实现大字号字段列表降级，但尚未单独做这一状态的 UI 自动化断言。
- 验证后已把该模拟器恢复为原有浅色 / large 字号，并清除测试状态栏覆盖。
- 浏览器研究任务空间已关闭；两项已批准技能安装完成，没有执行额外性能采集脚本。
