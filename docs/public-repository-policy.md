# 公开仓库与本机证据

本仓库发布源码、配置模板、技术说明、匿名化指标和明确标为合成的测试夹具。真实录音、完整转写、人物声纹、微信聊天导出、运行数据库、模型原始响应、登录凭据、签名私钥和用户截图不属于公开项目资产。

- `.build/`、`research/`、原始设备截图和私人配置保留本机，通过 `.gitignore` 排除。`research/` 包含网页原始快照及第三方资料；公开研究结论与来源链接在 `docs/` 中。
- `docs/validation/` 是经过人工检查的汇总，不是原始实验目录。公开指标保留失败、未知项和验收范围，转写正文不随指标发布。需要重放的私人材料由操作者自行提供，不提供用户录音下载链接。
- 文档中的 `<PROJECT_ROOT>`、`<LOCAL_HOME>`、`<IOS_DEVICE_ID>` 等是脱敏占位符。公开签名配置不带个人团队标识；在 Xcode 中为 `clients/project.yml` 生成的工程选择自己的签名团队；不要提交个人签名配置。
- 当前保留的一张事项反馈截图来自隔离模拟器，内容明确标为示例，没有连接真实工作区。

提交前运行 `python3 scripts/check-public-content.py --staged`，再用 Gitleaks 等完整凭据扫描器检查暂存内容和提交历史。脚本只输出文件位置与规则名；扫描报告放进忽略的 `.build/`，不要把原始密钥贴进 issue、PR 或日志。扫描工具不能代替对自然语言隐私内容的人工审查。

发布清理只处理公开项目文件，不删除用户卡上录音，不重跑 ASR，不修改线上数据库或运行服务。
