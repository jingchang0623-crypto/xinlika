## 新增的复现工具

`cb08-probe catalog` 只读取目录和录音状态，显式关闭校时，写入新建的私有证据目录；参数不接受录音控制、恢复控制或下载文件选项。相关自测 41/41 通过。

```bash
swift build --product cb08-probe
.build/debug/cb08-probe catalog --device UUID --output .build/新的目录
```

真实音频分段比较工具需要**明确指定已有固定快照**，避免自动遍历或批量上传全部个人录音：

```bash
python3 scripts/evaluate-voxgate-real.py --raw .build/已有快照.bin --seconds 300 --output .build/新的复核目录
```

它会上传整份、五个分钟批次和四个边界窗口，仅写本地复核材料；重用历史结果时，`--baseline` 的原始音频 SHA-256 必须匹配。可用 `--source-kind background_playback` 标记用户确认的背景播放样本，分类不由转写内容自动推断。脚本通过语法检查。所有样本解码均成功，但这不等同于语义正确。
