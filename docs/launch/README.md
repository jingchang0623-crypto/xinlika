# 心力卡传播素材包

版本：v0.2.0；整理于 2026-10-23。目标是吸引愿意实际运行、报告问题或扩展代码的用户与开发者。

**主张：iPhone 也能拥有随身上下文。项目所用录音卡硬件不到 200 元，自己部署、自己选模型；Android 跨品牌适配是下一步。**

不到 200 元是维护者提供的录音卡硬件价格参考，不是当前商家报价、整套成本或兼容保证；ASR、模型、服务器另计。OPPO 的兼容范围按[有日期的来源](../oppo-context.md)表述，不写成永久“只支持 OPPO”。
