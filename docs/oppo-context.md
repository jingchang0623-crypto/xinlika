# 与 OPPO 心力球的关系及对比依据

核查于 2026-10-23。心力卡 Xinlika 是独立项目，使用 CB08 录音卡和自己的处理服务，与 OPPO 无关联，不连接其硬件或服务。相近的用户目标是让日常上下文进入个人 Agent；这不是功能等价评测。

## 手机兼容性怎么说

[极客公园 2026-10-16 的实机报道](https://www.geekpark.net/news/372428)在软件体验段落说明：当时的心力球体验版需配合 OPPO、一加或 Realme 手机，其他品牌暂未支持。该文是有日期的媒体实机资料，不是永久兼容承诺。本轮未找到可核实所有机型的官方兼容清单。

因此对外采用以下表述：

> 看过 OPPO 心力球、但用 iPhone？心力卡提供原生 iPhone / Mac 源码和自托管后端，跨品牌 Android 是下一步。心力球当时体验版的手机范围，见 10 月 16 日实机报道。

不把“只支持 OPPO”当成准确的品牌清单；一加与 Realme 也在报道范围。也不由一篇体验报道推断未来永远没有 iPhone 支持。发布新内容前应重新核对。

## 心力卡自己的差异与代价

| 差异 | 可检查的实现 | 使用者承担的成本 |
|---|---|---|
| iPhone + Mac 原生路径 | `clients/`、[原生验证](native-validation.md) | 需要 Mac/Xcode，自行构建及 iPhone 实机签名 |
| 所用录音卡硬件不到 200 元 | 维护者于 2026-10-23 提供的项目硬件价格参考 | 非固定售价或整套成本；购买前核对型号、固件及价格 |
| 自托管与自选模型 | bootstrap/configure/start 脚本、兼容 ASR | 服务维护、ASR/模型及存储费用；外部模型会接收相应数据 |
| 保留来源，可重跑与纠正 | 原声/文字版本、引用、依赖失效与重问 | 原声存储、删除与使用授权需要管理 |
| 开放接入与改造 | 后端 MIT、客户端 GPL-3.0-only、接收协议 | Android/Watch/MCP 需要继续开发；新硬件/系统需实测 |

硬件价格由维护者提供，本页未独立核验订单或当前商家报价，不附未验证购买链接；不是特定店铺推荐。便宜或外观相似的录音卡不等于协议兼容。现有手机/电脑、自托管服务、ASR、模型与存储不计入该录音卡单价。不能从中推导相对竞品的省钱比例。

同一报道描述了心力球不保留转写后原音、项目追踪、IM/MCP 接入等能力。我们不将来源、项目或 Agent 这些共同方向宣称为独占功能，也不将自己尚未实现的 MCP 当作优势。原声保留与删除是不同选择；不能据此宣称谁更安全。

## 可核实的传播边界

可以说：受心力球启发；iPhone/Mac 源码已公开；项目所用录音卡硬件不到 200 元（维护者价格参考）；可自行部署；纠正和引用链路可复现；欢迎 fork 扩展 Android。

不能据现有证据说：兼容心力球硬件、OPPO 官方开源、所有 Android 已支持、免配置下载即用、全天零丢失、声纹百分百准确、完整平替、整套不到 200 元、全免费或有确定省钱比例。

本页不统计全网热度、销量或增长率；单条帖子阅读量不能代表市场规模。试用前读[完整运行方式](full-app.md)及[验证限制](evidence.md)。
