# iPhone 0.1.2（build 3）实现与验收记录

日期：2026-09-05。状态：开发签名包已安装到 iPhone 16 Pro，P0 实现进入真机验收；未发布 TestFlight，未标记为完整稳定版。

## 已实现的范围

- 蓝牙下载和云端上传解耦。下载按整 Opus 包持久化断点，恢复时校验文件身份、大小和已落盘内容；写入失败不把不完整录音当成成功。
- iOS 蓝牙状态恢复、意外断连事件、有限退避重连；进入后台时保存检查点，返回前台恢复任务。用户暂停保留内容，不删除设备录音。
- 云端使用文件型后台 URLSession PUT，保留回执并重新关联系统任务；控制步骤继续使用既有会话和幂等键，网络错误分类、有上限重试。用户强制退出后不承诺系统自动重启。
- 分开显示设备连接、上传、转写与分析状态。原生结果页展示摘要、分析正文、关键判断、行动项与参与者；网络失败保留最近一次结果和更新时间。
- 复用 Android 的 mobile transcript API、真实分析状态及未分析原因；普通刷新不重复触发分析。人工开始/重试分析需要用户确认可能消耗额度。
- 完整转写/回听使用一次性网页票据入口，隔离网页会话并限制同源导航。此入口尚未做生产真机验收。
- 有界、脱敏的诊断事件记录任务短标识、生命周期、字节进度和错误码；不写 token、录音正文或签名上传地址。

结果页沿用现有 SwiftUI 组件。Impeccable 的健壮性检查用于补充加载、缺失、失败、离线缓存和明确操作反馈，没有启动界面重设计。用户同意的技能更新尝试失败（下载包无效），未阻塞 App 构建。
